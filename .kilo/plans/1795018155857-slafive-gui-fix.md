# Fix SlaFive.java - Student Management System GUI

## Overview
SlaFive.java is a Swing-based Student Management System with CRUD operations. The file has several bugs and UI issues that need fixing.

## Current State Analysis

### File: `/home/chriscorex/java-practicals/SlaFive.java` (191 lines)

**What works:**
- Basic Swing GUI with JFrame, fields, buttons
- Insert, Update, Delete, Search, Exit functionality
- ArrayList-based in-memory storage
- findStudent() and clearFields() helpers

### Identified Issues

1. **Update functionality broken** - `updateStudent()` modifies the array elements directly, but since `String[]` objects in the ArrayList are mutable, changes should persist. However, the method only updates fields that are non-empty, meaning empty fields won't reset existing values. There's no "clear/Reset" button.

2. **Layout misalignment** - GridLayout(8, 2) expects 16 components but only 13 are added (title + empty + 5 label/field pairs + 5 buttons = 12, plus title row = 13). The last row is incomplete, causing buttons to be placed oddly.

3. **No input validation** - Year and Phone fields accept any text with no format checking.

4. **Search UX** - Search only fills fields; no dedicated details panel or clear button after search.

5. **No table/list display** - Inserted students are invisible; there's no JTable to show all records.

6. **Window size/padding** - 600x450 with 20px border may be cramped or excessive.

7. **Update clears only on success** - `clearFields()` is called after insert/update/delete, but no manual clear option.

## Proposed Fixes

### 1. Fix Layout
- Use a more flexible layout (GridBagLayout or panels with BoxLayout)
- Add a clear/reset button
- Ensure proper component alignment

### 2. Add Student Table Display
- Add a JTable below the form to show all students
- Refresh table after insert/update/delete
- Allow selecting a row to populate the form (for editing)

### 3. Improve Update Logic
- Make update work correctly (already mostly works, but verify)
- Add explicit clear button

### 4. Add Input Validation
- Phone: numeric only
- Year: numeric, reasonable range

### 5. Improve Search
- Search fills form AND highlights row in table

### 6. Better UI Structure
- Split into form panel (top) and table panel (bottom)
- Use modern styling consistent with other SLA files
